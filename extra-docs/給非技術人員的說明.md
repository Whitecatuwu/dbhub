# 用 ChatGPT 查詢公司資料：日常使用說明（給非技術人員）

這份說明告訴你：可以用 ChatGPT 問什麼、不能做什麼、怎麼問得準，以及出問題時怎麼辦。你**不需要懂程式或資料庫**，也**不需要自己安裝任何東西**，安裝由技術人員處理。


## 一、這是什麼？

公司的資料都存放在資料庫裡。平常要找資料，通常要請工程師幫忙寫查詢。

**DBHub** 是一座「橋」，讓你可以直接在 ChatGPT 用白話詢問資料庫，例如：

- 「這個月各部門的銷售總額是多少？」
- 「有哪些資料表跟客戶有關？」
- 「列出上個月建立的訂單，前 20 筆就好。」

ChatGPT 會幫你找到資料表、組出查詢，並把結果整理給你看。

```text
你（用白話提問）→ ChatGPT → DBHub（橋）→ 公司資料庫
```

## 二、你可以做什麼？

| 可以 | 說明 |
|---|---|
| 查看資料表與欄位 | 了解資料庫裡有哪些資料，以及各欄位代表什麼。 |
| 查詢資料 | 例如篩選、統計、排序、計算數量。 |
| 整理報表 | 請 ChatGPT 把結果整理成表格或摘要。 |
| 找出資料問題 | 例如找出空白或重複的資料。 |

## 三、你**不能**做什麼？

本專案設定為**唯讀**，正常使用下：

- **不能**新增、修改或刪除資料。
- **不能**更改資料庫的結構。
- 一次回傳的筆數有上限（由技術人員設定），資料量很大時會被截斷，屬正常設計。

## 四、使用前需要確認的事

由技術人員一次性設定完成後，你只需要：

1. **有 ChatGPT 帳號**（免費版或 Plus 皆可）。
2. **技術人員已在你的 ChatGPT 加入 DBHub 連接器**。你可以在 ChatGPT 的 Plugins 頁面看到它。
3. **負責執行的電腦是開機狀態**，且需要時已連上公司網路或 VPN（見上方聯絡窗口欄位）。這台電腦關機或休眠時，ChatGPT 就查不到資料。

> 你不需要、也不要自己去 OpenAI 網站建立隧道或 API Key。這些由技術人員處理。

## 五、第一次使用

1. 開啟一個**新的聊天**。
2. 選用 DBHub 連接器（依畫面操作；若看不到，請聯絡窗口）。
3. 第一次選用時，ChatGPT 可能會出現「自訂 MCP 伺服器會帶來風險。」的提示。這是 ChatGPT 對所有自訂連接器的通用警告，技術人員已確認這個連接器是公司自己的，確認後可以繼續。
4. 輸入一個簡單的問題，例如：「請列出資料庫裡有哪些資料表。」

如果能看到資料表名稱，代表連線成功。

## 六、提問的小技巧

- **說清楚範圍**：例如「2026 年 1 月到 3 月」比「最近」更容易得到正確結果。
- **先問結構再問資料**：先問「有哪些資料表」，再問「某張表有哪些欄位」，最後才問數字。
- **要求列出筆數**：例如「只列 20 筆」，避免一次跑出太多資料。
- **檢查結果**：ChatGPT 偶爾會誤解問題，重要數字請與原始報表核對。
- **不確定就問**：可以請 ChatGPT 說明它用了哪些資料表，以及查詢的邏輯。
- **不要期待它知道公司內部用語**：欄位名稱常是縮寫，請它先列出欄位，再用欄位名稱提問。

## 七、使用時要注意

- **查詢結果會顯示在 ChatGPT 的對話裡，並由 OpenAI 的服務處理。** 這些資料如何被保存或使用，取決於你的 ChatGPT 帳號的資料設定與公司規定。請向管理者確認：能查哪些資料、哪些欄位（例如個資、薪資）不應該查。
- **資料是公司機密**：不要把查詢結果貼到不相關的網站或聊天工具。
- **不要分享連接器或任何連線資訊**：這等同於進入資料庫的鑰匙。
- **結果僅供參考**：決策前請與負責的同事確認。
- 發現資料異常或連線出錯，請通知聯絡窗口，不要自己反覆嘗試。

## 八、常見問題

**Q：ChatGPT 說找不到 DBHub 或工具？**
確認你在新的聊天中選用了 DBHub 連接器。仍然不行，請聯絡窗口。

**Q：出現「連線失敗」或沒有回應？**
可能是負責執行的電腦沒開機、沒連上公司網路或 VPN，或資料庫暫時無法使用。請先確認自己的網路，再聯絡窗口。

**Q：為什麼查詢很慢？**
資料量大或條件太寬時可能較慢。請縮小時間範圍、減少欄位，或請技術人員協助。

**Q：查詢結果沒有我要的資料？**
可能是資料表名稱不同，或資料在另一個資料來源。請先問「有哪些資料表」，確認位置。

**Q：結果只有一部分？**
一次回傳筆數有上限，請縮小範圍或分批查詢。

**Q：可以用手機使用嗎？**
連接器是否能在手機上使用，以及電腦是否需要保持開機，請以聯絡窗口的說明為準。

**Q：有問題要找誰？**
請找本頁上方聯絡窗口所列的負責人。

## 名詞對照

| 名詞 | 白話解釋 |
|---|---|
| 資料庫 | 存放公司資料的系統。 |
| 資料表 | 資料庫中的一份「表格」，例如「客戶」「訂單」。 |
| 欄位 | 表格中的一欄，例如「客戶名稱」「金額」。 |
| 查詢 | 向資料庫提出的問題。 |
| 唯讀 | 只能看，不能改。 |
| 連接器 | ChatGPT 裡讓它能使用 DBHub 的一個項目。 |
| DBHub | 本專案，讓 ChatGPT 連到資料庫的橋。 |
