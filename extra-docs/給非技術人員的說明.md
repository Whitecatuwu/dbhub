# 用 AI 查詢公司資料：入門說明（給非技術人員）

這份說明告訴你：可以用 AI 問什麼、需要準備什麼，以及使用時要注意什麼。你**不需要懂程式或資料庫**。

## 一、這是什麼？

公司的資料都存放在資料庫裡。平常要找資料，通常要請工程師幫忙寫查詢。

**DBHub** 是一座「橋」，讓你可以直接用 AI 助理（例如 Claude）用白話詢問資料庫，例如：

- 「這個月各部門的銷售總額是多少？」
- 「有哪些資料表跟客戶有關？」
- 「列出上個月建立的訂單，前 20 筆就好。」

AI 會幫你找到資料表、組出查詢，並把結果整理給你看。

```text
你（用白話提問）→ AI 助理 → DBHub（橋）→ 公司資料庫
```

## 二、你可以做什麼？

| 可以 | 說明 |
|---|---|
| 查看資料表與欄位 | 了解資料庫裡有哪些資料，以及各欄位代表什麼。 |
| 查詢資料 | 例如篩選、統計、排序、計算數量。 |
| 整理報表 | 請 AI 把結果整理成表格或摘要。 |
| 找出資料問題 | 例如找出空白或重複的資料。 |

## 三、你**不能**做什麼？

本專案設定為**唯讀**，正常使用下：

- **不能**新增、修改或刪除資料。
- **不能**更改資料庫的結構。

若管理者開放了其他權限，請以管理者的設定為準，**不要自行嘗試**。

## 四、需要準備什麼？

1. **電腦上安裝 Claude Desktop**（Windows 或 Mac 版都可以）。
2. **DBHub 安裝檔**（通常是檔名結尾為 `.mcpb` 的檔案）。請向管理者或工程師索取。
3. **連線字串**：一行文字，由管理者另外提供。安裝時需要貼上，貼上後由 Claude Desktop 安全保存。你不需要自己建立資料庫帳號。

> 若想用 ChatGPT 而不是 Claude，請向管理者詢問。管理者需要先設定 OpenAI 的隧道（Tunnel）與權限（管理者請看 [ChatGPT連接說明.md](ChatGPT連接說明.md)），操作方式與本說明的 Claude Desktop 步驟不同。

> 你是管理者，要自己製作安裝檔？請看 [管理者發放指南（Claude Desktop）.md](管理者發放指南（Claude%20Desktop）.md)。

## 五、第一次使用的步驟

1. 向管理者取得 DBHub 安裝檔與連線資訊。
2. 雙擊 `.mcpb` 安裝檔，依畫面提示完成安裝。
3. 安裝過程會要求輸入「資料庫連線字串」，把管理者給你的那一行完整貼上。
4. 開啟 Claude Desktop，在對話框確認 DBHub 已連線（通常可在工具列或設定中看到它）。
5. 試著輸入一個簡單的問題，例如：「請列出資料庫裡有哪些資料表。」

如果第一次就能看到資料表名稱，代表連線成功。

## 六、提問的小技巧

- **說清楚範圍**：例如「2026 年 1 月到 3 月」比「最近」更容易得到正確結果。
- **先問結構再問資料**：可以先問「有哪些資料表」，再問「某張表有哪些欄位」，最後才問數字。
- **要求列出筆數**：例如「只列 20 筆」，避免一次跑出太多資料。
- **檢查結果**：AI 偶爾會誤解問題，重要數字請與原始報表核對。
- **不確定就問**：可以請 AI 解釋它用了哪些資料表，或它的查詢邏輯。

## 七、使用時要注意

- **資料是公司機密**：不要把查詢結果貼到不相關的網站或聊天工具。
- **不要分享安裝檔或連線資訊**：這些等同於進入資料庫的鑰匙。
- **不要在公用電腦上留下登入資訊**。
- **結果僅供參考**：決策前請與負責的同事確認。
- 發現資料異常或連線出錯，請通知管理者，不要自己反覆嘗試。

## 八、常見問題

**Q：AI 說找不到 DBHub 或工具？**
請確認 Claude Desktop 已完全重新啟動，並檢查 DBHub 是否已在工具列或設定中啟用。

**Q：出現「連線失敗」？**
可能是網路未連到公司內網、連線資訊過期，或資料庫暫時無法使用。請先確認網路，再聯絡管理者。

**Q：為什麼查詢很慢？**
資料量大或條件太寬時可能較慢。請縮小時間範圍、減少欄位，或請工程師協助。

**Q：查詢結果沒有我要的資料？**
可能是資料表名稱不同，或資料在另一個資料來源。請先問 AI「有哪些資料表」，確認位置。

**Q：可以用手機使用嗎？**
目前這個做法主要在電腦上的 Claude Desktop 運作，手機不一定支援，請以管理者說明為準。

**Q：有問題要找誰？**
請先找負責管理的工程師或系統管理者。

## 名詞對照

| 名詞 | 白話解釋 |
|---|---|
| 資料庫 | 存放公司資料的系統。 |
| 資料表 | 資料庫中的一份「表格」，例如「客戶」「訂單」。 |
| 欄位 | 表格中的一欄，例如「客戶名稱」「金額」。 |
| 查詢 | 向資料庫提出的問題。 |
| 唯讀 | 只能看，不能改。 |
| MCP | 讓 AI 助理能使用外部工具的一種標準。 |
| DBHub | 本專案，讓 AI 連到資料庫的橋。 |
