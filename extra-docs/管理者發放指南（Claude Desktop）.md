# 管理者指南：製作並發放 DBHub 安裝檔（Claude Desktop）

適用對象：負責替同事準備 DBHub 的管理者或工程師。同事端的操作請看 [給非技術人員的說明.md](給非技術人員的說明.md)。

這條路徑的做法：你把 DBHub 打包成一個 `.mcpb` 安裝檔，同事雙擊安裝，並在安裝時貼上資料庫連線字串。查詢在同事自己的電腦上執行，**不需要公開網路、Docker 或隧道**，但同事的電腦必須連得到資料庫（例如先連上公司 VPN）。

## 1. 先決定：是否要用這個方式

| 條件 | 是否適合 |
|---|---|
| 同事使用 Claude Desktop | 適合 |
| 同事只使用 ChatGPT | 不適合，請看 [ChatGPT連接說明.md](ChatGPT連接說明.md) |
| 每位同事要看不同資料 | 為每人（或每個角色）建立不同的資料庫帳號，再各自發放連線字串 |
| 需要多個資料庫、自訂工具 | 需自行修改打包用的 `mcpb/dbhub.toml`，見第 6 節 |

## 2. 準備資料庫帳號（最重要）

這個安裝檔內建「唯讀」限制，但**最終的保護還是資料庫帳號本身**。請資料庫管理者建立專用帳號：

- 只授予需要的資料庫的 `SELECT` 權限。
- 確認帳號允許從同事的電腦（或 VPN 網段）登入，而不是只允許 `localhost`。
- 不要使用 `root` 或 `admin` 這類高權限帳號。

## 3. 組出連線字串（DSN）

連線字串的格式，以 MySQL 為例：

```text
mysql://帳號:密碼@主機:3306/資料庫名稱
```

其他資料庫的格式見 [設定檔說明.md](設定檔說明.md)。

**密碼含有特殊字元時要做網址編碼**，否則連線會失敗：

| 字元 | 寫成 |
|---|---|
| `@` | `%40` |
| `:` | `%3A` |
| `/` | `%2F` |
| `#` | `%23` |
| `?` | `%3F` |
| 空白 | `%20` |

例如密碼 `p@ss#1`，字串寫成 `mysql://dbhub_reader:p%40ss%231@192.168.1.100:3306/product`。

> 這個安裝檔只接受整串連線字串，無法像 Docker 版那樣分開填密碼，因此需要編碼。

## 4. 製作 `.mcpb` 安裝檔

在你的電腦（需要 Node.js 22.5 以上與 pnpm），於專案資料夾的 PowerShell 執行：

```powershell
pnpm install
pnpm run build:mcpb
```

完成後安裝檔位於：

```text
dist-mcpb\dbhub-<版本>.mcpb
```

可選：用下面指令對安裝檔做連線冒煙測試（細節見專案根目錄的 `CLAUDE.md`）：

```powershell
pnpm run test:mcpb
```

## 5. 發放給同事

1. 把 `.mcpb` 檔案交給同事（內部共用資料夾或內部通訊工具即可）。
2. **另外**、用安全的方式把連線字串交給同事，例如密碼管理器或當面。不要寫在同一封郵件或同一個聊天室裡。
3. 請同事看 [給非技術人員的說明.md](給非技術人員的說明.md)。
4. 安裝檔本身**不含**密碼，連線字串由同事在安裝時輸入，Claude Desktop 會把它存在作業系統的金鑰儲存區。

同事第一次使用的驗收：請他問「請列出資料庫裡有哪些資料表」，看到資料表名稱即成功。

### 帳號異動時

- 同事離職：在資料庫端停用該帳號（若是每人一個帳號），或更換共用帳號的密碼並重新通知其他人。
- 密碼更換：同事需在 Claude Desktop 的擴充功能設定中更新連線字串。

## 6. 想改預設行為時

安裝檔內建的規則在 `mcpb/dbhub.toml`：只有 `execute_sql`（唯讀、最多 1000 筆）與 `search_objects`。若要多個資料庫或自訂工具，修改該檔案後重新執行 `pnpm run build:mcpb`。

注意：專案測試會檢查 `plugin/dbhub.toml` 與 `mcpb/dbhub.toml` 是否一致，只改其中一份可能讓測試失敗。

## 7. 常見問題

| 狀況 | 處理 |
|---|---|
| `pnpm` 找不到 | 先安裝 Node.js，再執行 `corepack enable` 或 `npm install -g pnpm` |
| 同事雙擊 `.mcpb` 沒反應 | 確認已安裝 Claude Desktop 且為較新版本；也可在 Claude Desktop 的設定中手動安裝擴充功能 |
| 同事回報「連線失敗」 | 先確認他的電腦能連到資料庫（VPN、防火牆），再檢查連線字串與密碼編碼 |
| 查詢結果被截斷 | 內建上限為 1000 筆，屬正常設計 |
